Available Commands

            

                

                    
Movement

                    
    
                        
  • FORWARD n or FD n - Move forward n pixels
    • 
                        
  • BACKWARD n or BK n - Move backward n pixels
    • 
                        
  • LEFT n or LT n - Turn left n degrees
    • 
                        
  • RIGHT n or RT n - Turn right n degrees
    • 
                        
  • SETXY x y - Move to position (x, y)
    • 
                        
  • SETX n - Set X position to n
    • 
                        
  • SETY n - Set Y position to n
    • 
                        
  • SETHEADING n or SETH n - Set heading (0=right, 90=up)
    • 
                        
  • HOME - Return to center (0, 0) facing up
    • 
                    

                

                

                    
3D Movement & Rotation

                    
    
                        
  • UP n - Pitch up n degrees (3D mode)
    • 
                        
  • DOWN n or DN n - Pitch down n degrees (3D mode)
    • 
                        
  • ROLLRIGHT n or RR n - Roll right n degrees (3D mode)
    • 
                        
  • ROLLLEFT n or RL n - Roll left n degrees (3D mode)
    • 
                        
  • SETZ n - Set Z position to n (3D mode)
    • 
                        
  • SETXYZ x y z - Move to 3D position (3D mode)
    • 
                    

                

                

                    
3D Shapes & Faces

                    
    
                        
  • BEGINFACE - Start recording vertices for a filled polygon
    • 
                        
  • ENDFACE - End face and render filled polygon
    • 
                        
  • SETFACECOLOR n - Set face color from palette (0-15)
    • 
                        
  • SETFACERGB r g b - Set face color using RGB values
    • 
                        
  • MAKE "m1 SPHERE 50 - Create sphere, store reference in variable
    • 
                        
  • MAKE "m2 CUBE 80 - Create cube, store reference in variable
    • 
                        
  • MAKE "m3 CYLINDER 30 100 - Create cylinder, store reference in variable
    • 
                        
  • LASTMESH - Returns reference to most recently created mesh
    • 
                    

                

                

                    
CSG Operations (Boolean)

                    
    
                        
  • MAKE "result UNION :mesh1 :mesh2 - Combine two meshes
    • 
                        
  • MAKE "result SUBTRACT :mesh1 :mesh2 - Cut mesh2 from mesh1
    • 
                        
  • MAKE "result INTERSECT :mesh1 :mesh2 - Keep only overlapping volume
    • 
                        
  • Example: SPHERE 50 MAKE "s1 LASTMESH CUBE 80 MAKE "c1 LASTMESH SUBTRACT :s1 :c1
    • 
                    

                

                

                    
Pen Control

                    
    
                        
  • PENUP or PU - Lift pen (stop drawing)
    • 
                        
  • PENDOWN or PD - Lower pen (start drawing)
    • 
                        
  • PENSIZE n - Set pen width to n pixels
    • 
                        
  • SETPENCOLOR n or SETPC n - Set pen color from palette (0-15)
    • 
                        
  • SETPENRGB r g b - Set pen color using RGB values (0-255)
    • 
                    

                

                

                    
Display & Shapes

                    
    
                        
  • CLEAR - Clear all drawings
    • 
                        
  • HIDETURTLE or HT - Hide the turtle
    • 
                        
  • SHOWTURTLE or ST - Show the turtle
    • 
                        
  • CIRCLE radius - Draw a circle
    • 
                        
  • BOX width height - Draw a rectangle
    • 
                        
  • SQUARE size - Draw a square
    • 
                    

                

                

                    
Variables & Control

                    
    
                        
  • MAKE "var value - Set variable
    • 
                        
  • :var - Use variable value
    • 
                        
  • "word - Quoted word (single word, no closing quote needed)
    • 
                        
  • "text with spaces" - String literal with spaces (closing quote required)
    • 
                        
  • LOCAL "var or LOCAL [var1 var2] - Declare local variable(s)
    • 
                        
  • REPEAT n [commands] - Repeat commands n times (use REPCOUNT for iteration)
    • 
                        
  • DOTIMES [var count] [commands] - Like REPEAT but with named variable (1 to count)
    • 
                        
  • WHILE condition [commands] - Loop while condition is true
    • 
                        
  • FOR [var start end increment] [commands] - Loop with counter (increment optional)
    • 
                        
  • TO name :param1 :param2 ... [commands] END - Define procedure
    • 
                        
  • OUTPUT value - Return value from procedure
    • 
                        
  • STOP - Exit procedure without returning value
    • 
                        
  • INCLUDE "url" - Load and execute Logo code from URL (build libraries!)
    • 
                        
  • PRINT value or PR value - Output value to console (with newline)
    • 
                        
  • WRITE value or WR value - Output value to console (without newline)
    • 
                    

                

                

                    
Arithmetic & Math

                    
    
                        
  • +, -, *, / - Basic arithmetic
    • 
                        
  • ^ - Exponentiation (e.g., 2 ^ 3 = 8)
    • 
                        
  • MOD - Modulo operation
    • 
                        
  • POWER base exp or POW base exp - Exponentiation function
    • 
                        
  • SQRT n - Square root
    • 
                        
  • SIN n, COS n, TAN n - Trigonometry (degrees)
    • 
                        
  • ABS n - Absolute value
    • 
                        
  • ROUND n, FLOOR n, CEILING n - Rounding
    • 
                        
  • RANDOM n - Random integer 0 to n-1
    • 
                        
  • ( ) - Parentheses for grouping
    • 
                    

                

                

                    
Comparisons

                    
    
                        
  • < - Less than
    • 
                        
  • > - Greater than
    • 
                        
  • = - Equal to
    • 
                        
  • <= - Less than or equal
    • 
                        
  • >= - Greater than or equal
    • 
                        
  • <> - Not equal
    • 
                    

                

                

                    
Logical Operators

                    
    
                        
  • AND - Logical AND
    • 
                        
  • OR - Logical OR
    • 
                        
  • NOT - Logical NOT
    • 
                    

                

                

                    
Conditionals

                    
    
                        
  • IF condition [commands] - Execute if true
    • 
                        
  • IFELSE condition [true] [false] - Conditional execution
    • 
                    

                

                

                    
Query Functions

                    
    
                        
  • XCOR - Returns current X coordinate
    • 
                        
  • YCOR - Returns current Y coordinate
    • 
                        
  • HEADING - Returns current heading (0-360)
    • 
                        
  • PENDOWN? or PENDOWNP - Returns 1 if pen is down, 0 if up
    • 
                        
  • PENSIZE - Returns current pen size
    • 
                        
  • PENCOLOR - Returns current pen color as list [r g b]
    • 
                        
  • REPCOUNT - Returns current iteration number in REPEAT loop (1-indexed)
    • 
                    

                

                

                    
Lists & List Operations

                    
    
                        
  • [item1 item2 ...] - List literal
    • 
                        
  • FIRST list - Returns first element
    • 
                        
  • LAST list - Returns last element
    • 
                        
  • BUTFIRST list or BF list - All but first element
    • 
                        
  • BUTLAST list or BL list - All but last element
    • 
                        
  • ITEM n list - Get nth element (1-indexed)
    • 
                        
  • COUNT list - Returns list length
    • 
                        
  • EMPTY? list - Returns 1 if empty, 0 otherwise
    • 
                        
  • FPUT item list - Add item to front of list
    • 
                        
  • LPUT item list - Add item to end of list
    • 
                        
  • LIST item1 item2 - Create list from items
    • 
                        
  • SENTENCE list1 list2 or SE list1 list2 - Flatten/concatenate
    • 
                        
  • MEMBER? item list or MEMBERP item list - Check if item in list
    • 
                        
  • POSITION item list - Find 1-based index (0 if not found)
    • 
                    

                

                

                    
Higher-Order Functions

                    
    
                        
  • MAP "proc list - Apply procedure to each element (can be used as command or function)
    • 
                        
  • FILTER "pred list - Keep elements where predicate is true (can be used as command or function)
    • 
                        
  • REDUCE "op list - Reduce list to single value (can be used as command or function)
    • 
                        
  • APPLY "proc arglist - Call procedure with argument list (can be used as command or function)
